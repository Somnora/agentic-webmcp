Privacy for the public demo

Effective August 25, 2026

Agentic WebMCP is a stateless, read-only demonstration. It does not create user accounts, set cookies, request payment information, or store catalog searches, selected products, or generated briefs in an application database.

Infrastructure data

Cloudflare hosts the application and may process standard request and security metadata needed to deliver and protect the service. The application has Cloudflare Worker observability enabled for operational reliability. Do not enter personal or confidential information into the public demo.

Catalog data

The Worker retrieves public demonstration products from Shopify Mock Shop. Search terms stay within the Agentic Worker; the upstream request fetches a fixed public catalog sample and does not include an Agentic visitor identity. If Mock Shop is unavailable, the page clearly labels its bundled fallback snapshot.

Agent tools

The four WebMCP tools are read-only. They expose no account, cart, checkout, order, customer, billing, or product-mutation capability. Tool activity exists only in the open browser page and disappears when that page is closed or reloaded.

Contact and source

Questions may be sent to support@somnora.app. The complete public implementation is available on GitHub.
