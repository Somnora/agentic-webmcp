Privacy for the public demo

Effective August 25, 2026

Agentic WebMCP is a stateless demonstration. It does not create user accounts, set cookies, request payment information, or store origin selections, searches, recommendations, purchase reviews, approved selections, or generated briefs in an application database.

Infrastructure data

Cloudflare hosts the application and may process standard request, URL, security, log, and trace metadata needed to deliver, monitor, and protect the service. Application error records contain only the route path, stable error code, and retryability. There are no third-party analytics identifiers. Do not enter personal or confidential information into the public demo.

Catalog data

The Worker reads only exact HTTPS hostnames and paths declared in its origin allowlist. The default origin is agentic-webmcp-origin.somnora.workers.dev, a controlled public guitar marketplace with original listings and no external product images. Its JSON and HTML responses are fetched live and clearly labeled as controlled demonstration data. The secondary Shopify development store can use a read-only Storefront token, public products JSON, or a clearly labeled bundled snapshot. Search terms do not include an Agentic visitor identity.

Agent tools

Eight WebMCP tools read origins, offers, ranked recommendations, and stripped page content. propose_add_to_cart stages a purchase review but does not create an order. Only the human approval button can create an in-page decision record. No tool exposes checkout, payment, account, order, customer, billing, or merchant mutation capability. Tool activity disappears when the page is closed or reloaded.
